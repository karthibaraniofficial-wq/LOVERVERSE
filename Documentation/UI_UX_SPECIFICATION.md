# LOVEVERSE - UI/UX Specification

## Cross-Platform Controls
### Android Touch Controls
- **Left Screen Area:** Floating virtual analog joystick with deadzone and dynamic re-centering.
- **Right Screen Area:** Free touch delta camera drag.
- **Action Buttons:** Jump, Sprint toggle, Contextual Interact ("Hold Hands", "Sit", "Open Menu"), Photo Mode shortcut.

### Windows Keyboard & Mouse
- `W/A/S/D`: Locomotion
- `Mouse Movement`: Orbit camera
- `Space`: Jump
- `Left Shift`: Sprint
- `E`: Contextual Interact
- `P`: Photo Mode
- `M`: World Map
- `Esc`: Pause / Settings

## Design Aesthetic
- Translucent frosted glass backgrounds (`rgba(255, 255, 255, 0.75)` or dark glass for night mode).
- Rounded pill buttons with gentle scale bounce on tap/click.
- Accessible contrast ratios and dynamic notch / safe-area handling.
